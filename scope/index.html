02 · The loop

How the fly actually applies

One closed loop, which is the thing most viral fly demos skip. The board's outcome goes back into the brain as taste-neuron stimulation.

What is real

  • The wiring. Every synapse in the sim comes from the MaleCNS v1.0 connectome, brain and ventral nerve cord together.
  • The dynamics. Leaky integrate-and-fire over that wiring, the same class of model behind the viral demos and the 2024 whole-brain fly papers.
  • The neuron identities. DNg100 is a named descending neuron, 2 cells. The 23 sugar neurons are LB3c (Gr64f+) and the 38 bitter neurons are LB1a–d (Gr33a+), matched in the 2026 gustatory connectome paper in Cell.
  • The clicks. Playwright only acts when the readout neuron crosses threshold. Nothing is scripted on the browser side.

What is not

  • Sensing. The fly never sees the posting. Its only input is the reward and punishment we inject, so the output is noise shaped by the wiring.
  • Learning. Nothing in the loop changes synaptic weights, so it cannot get better at applying. That is the joke and the caption says so.
  • The job board. A local mock with an endless feed and one giant Easy Apply button. Real portals would dump 1,000 junk applications into real recruiters' queues.
  • The effect of taste. Sugar and bitter input light up the taste neurons but do not measurably change DNg100's click rate, tested across seeds. It cannot learn to apply better.
03 · What got built

All five phases shipped

The original plan, with notes on where the build departed from it.

PHASE 0no deps

Mock job board and inbox

A single local web app: infinite feed of generated postings, an Easy Apply button that fills the viewport, a Workday-parody form that forgets the uploaded résumé, and an inbox pane that receives scripted rejections on a timer.

  • Stack: one Node process, Express plus a static page. No database, state in memory, seeded so the montage is repeatable.
  • Events: the board POSTs applied, rejected, interview, retype to a local event bus the sim subscribes to.
  • Comic timing knobs: rejection latency, interview rate (start at 0.8%), copy bank for rejection emails.
Doneaiohttp, not Express
PHASE 1no deps

Brain sim with the right neurons wired to the right pins

Start from the Mario 64 fly repo cited in the earlier chat, which already maps neurons to controller buttons, or from the published whole-brain LIF code. Pull the MaleCNS connectivity from neuPrint, look up the neuron IDs by cell type, and expose three pins.

  • Output pin: DNg100 spike rate over a 200 ms window. Above threshold means "apply." A second DN can drive "scroll."
  • Input pins: a current injection into LB3c sugar GRNs, and one into LB1a–d bitter GRNs, each held for 500 ms per event.
  • Spike stream: every spike goes out as (neuron id, t) over a WebSocket for the viewer. Downsample to the neurons that exist in the mesh set.
  • Risk: DNg100 may sit silent without sensory drive. Fallback is background Poisson input to sensory neurons so the brain idles at a realistic rate.
Doneruns on CPU, 0.8–0.9× real time
PHASE 2needs 0, 1

Playwright glue

A loop of about 80 lines: read the DN rate, act on the board when it crosses threshold, forward board events into the input pins. Headed browser so it can be screen-captured.

  • Rate limit: one action per 700 ms max, otherwise 1,000 applications takes 12 minutes and the time-lapse is boring.
  • Counter overlay: the board renders the burned-in counter itself, so the capture needs no compositing.
Doneone click per spike
PHASE 3needs 1

3D viewer with real geometry

Keep this page's renderer and swap the stand-in for the real thing. Portrait render mode at 1080×1920 with the same HUD.

  • Neuropil meshes: the MaleCNS dataset on neuPrint exposes brain and VNC region meshes. Fetch with navis, decimate, export glTF, load with three's GLTFLoader.
  • DNg100 skeleton: pull the SWC, render as a polyline with the same traveling pulse this page uses.
  • Soma cloud: real soma positions from the annotation table, one point per neuron, typed by cell class so the sugar and bitter clusters light in the right place.
  • Live: subscribe to the spike WebSocket and flash the matching points. The hologram body stays; nobody needs a photoreal fly.
Donefly at a desk, live monitor
PHASE 4needs all

Capture and cut

Two OBS sources stacked in a 9:16 canvas: viewer on top, board and inbox below. Record one 12-minute run, cut the time-lapse, record the VO last against picture.

  • Deliverable: 1080×1920, 30 fps, 35 s, captions burned in, plus the honest caption as the post text.
  • Sound: inbox ping on every rejection, one warmer chime on the interview.
Doneautomatic edit, no OBS
